### Limits of the strata

- **import:** the store keeps the specifier and the span of the statement, not the file it names; atlas works the file out when a question is asked. The verifier checks the specifier at the span with a fresh parse and, for a relative specifier, that the oracle's emit-aware resolution finds either no program file or one the index holds.
- **reference_edge:** the build's eager pass asks only for sites in files that a compiler configuration owns (35,727 sites asked, 15,273 edges stored at atlas commit 15ffc48 and 15,272 since the `mapTarget` fix); a site outside every configuration has no precise edge and is not in this population.
- **relation:** gsd-core has no `implements` and no `override` (the research census); both are listed with zero. `implements` and `overrides` are proved on fixtures in `scripts/relations-check.test.ts` and `scripts/edge-sample.test.ts`.
- **definition:** the kind check uses the compiler's reading of the declaration; the qualified-name check uses the scoping rules the grammar modules document.
- **A fact whose file differs from the indexed version** (the blob id of the checkout file is compared with the one the overlay recorded) or is in no TypeScript program counts as unverifiable and therefore wrong. No fact of this sample was either.
