<objective>
Freeze the shared kernel (`src/facts`), the adapter-facing `HostClient` interface, and the test kit (`FakeClock`, Windows-safe temp directories) so every seam in later plans is built against the same types and doubles.

Phase goal (ROADMAP.md, quoted verbatim): "A developer can build and test the repo on macOS, Linux and Windows and run `gsd-atlas lang test` on a fixture language module end to end, with every module seam frozen behind an interface and a test double."

This plan runs in wave 1 beside the scaffold (plan 01-01) and uses only Node built-ins and `node --test` type stripping, so it needs no installed dependencies.

Purpose: ARCHITECTURE.md names the FileFacts contract and the Request/Envelope/HostClient contract as the first seams to freeze because producer, carrier and consumer are built in parallel. Plans 01-09 to 01-14 import from here.
Output: `src/facts/*`, `src/host-client/*`, `src/test-kit/*` with tests.
</objective>
