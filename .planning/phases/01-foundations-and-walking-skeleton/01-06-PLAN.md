<objective>
Define the language-module manifest as a strict, versioned Zod schema, generate and commit the matching JSON Schema, and prove with an Ajv test that the parser and the schema agree on a fixture set.

Phase goal (ROADMAP.md, quoted verbatim): "A developer can build and test the repo on macOS, Linux and Windows and run `gsd-atlas lang test` on a fixture language module end to end, with every module seam frozen behind an interface and a test double."

Purpose: FND-03 and decisions D-04, D-05, D-06. The manifest shape is `costly` to change (third-party and user modules in Phase 9 will depend on it), so the field set is settled by a human decision before any code is written.
Output: `src/lang/manifest.ts` and tests, `scripts/schema-build.ts`, `schemas/atlas-lang.schema.json`, twelve fixture manifests.

Path confinement against the real disk is plan 01-12, `lang test` is plan 01-14, and the registry, `lang list` and the skipping of invalid modules are plan 01-17.
</objective>
