## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provider or module data to process spawn | A repo, npm package or user module must never be able to cause an arbitrary command to start. |
| child process output to host memory | A hostile or buggy child can stream unbounded output or hang. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-01-20 | Elevation of Privilege | spawning a non-built-in or shell-interpreted command | high | mitigate | argv arrays with shell false; decide() exact built-in table and arg validation (git subcommand and -c key allowlists); user permissions injected, never read from repo; contract scenario proves a denied spec starts nothing. |
| T-01-21 | Denial of Service | unbounded output or a hung child | medium | mitigate | stdout cap kills the child and reports truncation; per-spec timeout with SIGKILL; stderr cap truncates. |

| T-01-23 | Information Disclosure | secrets and git redirection variables inherited by children | low | mitigate | scrubEnv denylist removes secret-looking names and GIT_DIR-style variables before the overlay. |
