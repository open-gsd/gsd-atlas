## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-03-101 | Tampering | agent writing or exfiltrating through the shell | high | mitigate | Read-only allowed-pattern list, no Edit, Write, Task or network tools, per-cell throwaway clone, budget and wall-clock bounds, init event compared with the registered tool set on every session. |
| T-03-102 | Information Disclosure | user configuration or hooks leaking into a session | medium | mitigate | Empty setting sources, strict MCP config, empty per-session `GSD_ATLAS_USER_DIR`; contamination aborts the run. |
| T-03-103 | Tampering | a scored run on an unfrozen or altered harness | high | mitigate | `--scored` runs `verifyPrereg` first and checks the skill hash; exit 2 otherwise. |
| T-03-104 | Repudiation | selective retries improving one arm | high | mitigate | Only infrastructure failures retry, at most twice, each attempt logged; model-reached sessions are final. |
| T-03-105 | Denial of Service | runaway concurrency or cost | medium | mitigate | Concurrency from the approved constants, per-session budget and wall-clock bounds, `plan` shows the counts before any session. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package. |
