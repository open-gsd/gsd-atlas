    - "D-02: the oracle is a compiler-derived answer-key generator that never imports atlas. Expected answers come from the TypeScript compiler symbol table (the checker, `getOutputFileNames`, the scanner for comments) plus `git ls-files` and `git grep` cross-checks; tree-sitter is never used to grade tree-sitter."
    - "A question's key is computed by one function, `computeAnswerKey(key, ctx)`, for these kinds: callers, references, heritage (subtypes and supertypes), emit (source to output path), emit-consumers (files requiring the emitted output), adr-citers (files and lines whose comments cite ADR n), adr-of (ADRs cited by a named declaration and the ADR file or files with that number), definition, impact (callers to a stated depth, at file level) and abstain (a probe that must find nothing)."
    - "CommonJS consumers are part of the truth: a destructured `require` of a module that resolves, through the emit map (output path back to its `.cts` source), to the defining file counts as a reference to the symbol, and so does a `.cjs` file requiring the emitted output. The checker alone cannot see these (research Pattern 2: 2,756 destructured-require bindings have no declaration link), so the oracle resolves them with its own, separate rule."
    - "Every key carries a granularity (`file`, `file+symbol` or `file+line`) and an equality rule (`exact-set` or `superset-ok`), and the oracle reports an `unexplained` list: textual mentions found by `git grep -nw` that the compiler-based result neither includes nor classifies as a string, comment or unrelated same-named symbol. A question with a non-empty `unexplained` list is flagged ambiguous for the author (plan 03-09)."
    - "ADR citations in the oracle follow D-19: `ADR-<n>`, `ADR <n>` and `ADR #<n>` inside comments only (found with the compiler's scanner, so a mention inside a string literal is excluded), case-insensitive, an optional section suffix such as `§3` kept as detail, numbers compared by value (leading zeros ignored)."
    - "[edge EVL-02/abstain] An abstain key is produced only after the probe is verified to match nothing: no declaration with the name in the program, no `git grep -w` hit outside comments and strings, or no ADR file with that number; if the probe matches anything, `computeAnswerKey` throws with the matches listed so the author fixes the question."
