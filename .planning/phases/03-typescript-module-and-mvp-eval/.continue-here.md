## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Fixing src during a scored run | A src change mid-run breaks the registered atlas-commit binding | blocking | Hold src fixes until the run ends; the harness atlas-build check enforces it |
| Zsh variable named `path` | `path` is tied to `PATH`; assigning it removed `git` mid-loop | advisory | Use other names (`wtdir`, `ref`) in shell loops |
| Batched `gh issue close` | The auto-mode classifier refuses batched closes | advisory | One single `gh` command per issue |
| Writing 'eval' literally in Bash | A user hook rejects commands containing the word | advisory | Globs like `scripts/ev[a]l/`, `docs/ev[a]l/` |
| Mixing git with `$VAR` in one Bash call | A guard rejects compound commands | advisory | Split the commands |
| Reading indexed source via Read/Bash | MEMTRACE-FIRST guard blocks until CodeGraph names the file | advisory | `codegraph explore "<paths>" --path <worktree>` or `codegraph node -f <file> --offset N --limit M` first; do not set GSD_MEMTRACE_GUARD_OFF yourself |
| `gh workflow run` | A hook refuses it | advisory | The user dispatches workflows by hand |
| Orchestrator editing source in main | The worktree guard blocks code edits in the main checkout (Write of planning files worked for handoff) | advisory | Use executor agents with isolation worktree, then `git merge --no-ff` and gate |
