## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-61 | Tampering | installers of third-party tools | high | mitigate | Blocking-human approval of the exact list; scratch prefix, no global or root install; pinned versions recorded; scratch directory deleted; tools run only against a throwaway checkout. |
| T-03-62 | Denial of Service | live-run cost | medium | mitigate | Per-session budget and wall-clock caps from the approved constants; sessions that hit a cap are recorded, not retried. |
| T-03-63 | Information Disclosure | transcripts or home paths in committed run files | medium | mitigate | Run files hold counts, ids and short gap notes only; a test greps them for the home directory path. |
