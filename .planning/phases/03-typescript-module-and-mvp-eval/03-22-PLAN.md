## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tsconfig content to which files are indexed | A hostile config could try to hide files by declaring them outputs. |
| specifier text to file identity | An import path resolved through a map must not point outside the overlay. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-03-221 | Tampering | a config naming `outDir` over real source to drop it from the index | medium | mitigate | A path that is a source of any config is never treated as an output; `emit_overlaps_source` diagnostic; test. |
| T-03-222 | Tampering | ambiguous output paths resolving to a wrong source | medium | mitigate | Ambiguity returns no mapping and a diagnostic; the plain rule applies. |
| T-03-223 | Information Disclosure | `emittedAs` listing paths outside the repository | low | mitigate | Output paths are repository-relative POSIX strings built from `outDir`; a config escaping the root has its outputs dropped with a diagnostic. |
| T-03-224 | Denial of Service | re-describing the project on every edit | medium | mitigate | Memoised by path set and config hashes; a test counts `describe` calls over ten edits of one source file (one call). |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package. |
</threat_model>
