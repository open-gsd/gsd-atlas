<objective>
Let a user rate the last answer, a feature or the session in one command, with a local record that holds ids and codes only. To make that possible across processes, stamp every answer with an id and keep the capped local flight recorder that `gsd-atlas bug` will also read.

Phase goal (ROADMAP.md, quoted verbatim): "A developer working on gsd-core gets compiler-precise, cited answers (callers, implementers, `.cts` to `.cjs` emit mapping, ADR citations) with `explain`, and agents using atlas consume fewer tokens than a grep-only baseline at non-inferior accuracy."

Output: the Host answer-id stamp, the tenant flight recorder, the ratings migration and event, the `rate` request and command.
</objective>
