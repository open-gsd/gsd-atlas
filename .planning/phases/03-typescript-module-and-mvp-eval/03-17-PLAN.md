    - Rotation is a rename of the current segment over the previous one; a test runs two recorder instances on the same directory appending 200 events each concurrently (interleaved with `await` points) and then reads: every readable line parses, the newest event of each instance is present, and the count is at most the cap.
    - A reader started while a rotation is in progress never throws (a missing segment is treated as empty).
    - `clear()` removes both segments and is the operation `bug --clear` will call later; after it `recent(5)` is empty.
    - A follower process (no writer lease) records too: the recorder needs no lease; two OS processes appending (a child process test with 100 appends each) leave only complete lines.

  </behavior>
