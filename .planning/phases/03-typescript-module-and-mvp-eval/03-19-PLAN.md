## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| composition root to the runner | The shape table is the only way a non-git, non-user process starts; it must be exact. |
| worker to the machine | The worker runs repository-influenced JavaScript (the project's compiler) in a child. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-03-191 | Elevation of Privilege | a spec resembling the worker's but with a different argument, flag or path being started | critical | mitigate | Exact-shape matching with anchored patterns and a literal worker path; at least twelve deviation tests; the claim of the built-in id is required. |
| T-03-192 | Elevation of Privilege | environment injection (`NODE_OPTIONS`, preload variables) | high | mitigate | The shape lists the only env key allowed; the caller supplies a minimal environment; a test prints the worker's environment. |
| T-03-193 | Denial of Service | orphaned or runaway workers | medium | mitigate | Exit on stdin end, `kill()`, parent-death test, no process left after kill. |
| T-03-194 | Denial of Service | cumulative stdout cap killing a healthy worker | medium | mitigate | Per-spec `maxStdoutBytes` set to the approved `precise.maxStdoutBytes`; the default cap behavior pinned by a test. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package. |
