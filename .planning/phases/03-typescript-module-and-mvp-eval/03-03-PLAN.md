## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| harness to `claude` child | The child is an agent with shell access to a throwaway checkout and the user's authentication. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-31 | Tampering | eval agent with a shell modifying or exfiltrating | high | mitigate | Argument array, no shell; tool set fixed by `--tools` and read-only `--allowedTools` patterns; no network tools; throwaway checkout as cwd; init event asserted against the registered tool set by the caller. |
| T-03-32 | Denial of Service | runaway cost, time or output | medium | mitigate | `--max-budget-usd` per session, wall-clock SIGKILL, stdout cap, stderr ring; tests for each bound. |
| T-03-33 | Information Disclosure | committed fixtures carrying session ids, paths or account names | medium | mitigate | Fixtures are sanitised to fixed placeholders before commit; a test greps the fixtures for the home directory path and fails if present. |
| T-03-34 | Spoofing | model output shaped like protocol events | low | accept | Parsing reads only the documented event types by `type` field; unknown shapes are counted and ignored; nothing the model writes is executed. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package. |
