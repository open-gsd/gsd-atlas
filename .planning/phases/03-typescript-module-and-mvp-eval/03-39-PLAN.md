## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| resolver to the store | An adapter returns edges; a buggy or hostile one must not corrupt facts or read the store. |
| project context to the cache | A wrong context key would serve edges computed under another configuration. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-202 | Tampering | edges cached under the wrong context after a concurrent commit | high | mitigate | Context computed per snapshot id, recomputed once on mismatch, otherwise degrade without caching; controlled-race test. |
| T-03-203 | Denial of Service | provider or resolver blocking reads | medium | mitigate | The resolver call stays bounded by `query.resolveTimeoutMs`; a provider that throws or loses the race degrades to grammar-tier answers. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package. |
