## Artifacts this phase produces (plan 03-07)

- `scripts/eval/answer-schema.json`: JSON Schema (draft 2020-12) for `{ answer: 'found' | 'not_found', items: [{ file: string, line?: integer >= 1, symbol?: string }], summary: string (maxLength 400) }`, `additionalProperties` false everywhere.
- `scripts/eval/score.ts`: `AnswerSchema` (zod twin of the JSON Schema, with a test proving they accept and reject the same samples); `LINE_SLACK` = 2; `extractAnswer(resultText): {ok: true, answer} | {ok: false, reason}`; `scoreAnswer(question, key, answerText, ctx): Promise<Scored>` where `Scored` = {correct, reason, answered, matched, missing, extra, citation: {applicable, total, verified, hasVerifiable, failures}}; `toResultRow(partial, scored)` building a `ResultRow` (plan 03-05 schema).
- `scripts/eval/prepare-corpus.ts`: `prepareCorpus({id, dest, npmCi, fetchCommand?})` returning a `PreparedRecord` {corpusId, sha, npmCi, typescriptVersion|null, lockSha256|null, dir}; writes `<dest>/<name>/.eval-prepared.json`; `readPreparedRecord(dir)`; `cloneCheckout(from, to)`; command line `node scripts/eval/prepare-corpus.ts --corpus gsd-core --dest <dir> [--no-npm-ci]`.
