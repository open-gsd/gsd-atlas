## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository content to the permission rule | Manifests, config files and package scripts are attacker-controlled when the repository is hostile. |
| user config to the runner | The only source of permissions; a half-applied or widened entry changes what runs. |
