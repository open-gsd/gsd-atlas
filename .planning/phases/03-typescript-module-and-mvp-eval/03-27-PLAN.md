## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker memory use to the host machine | A compiler program on a big repository can exhaust memory on a developer machine or CI runner. |
| sampler kill to correctness | Killing the wrong thing or too late harms reliability. |
