<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| machine data to a report | Values describing the user's machine and repository become text that may later be published. |
| repository content to consent | A hostile repository must not turn collection on. |
| user note to the report | Free text can carry paths and secrets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-03-211 | Information Disclosure | identifying names, paths or secrets reaching a report | high | mitigate | Only catalog fields are collected; counts and sizes are bucketed; the privacy fixture test (acceptance test 4) asserts five markers are absent from the whole rendered report; notes are scrubbed. |
| T-03-212 | Elevation of Privilege | a repository enabling diagnostics or auto-submit | high | mitigate | Consent is read from the user directory only; a test with a read-recording filesystem proves no repository file is opened; the committed-config fixture shows no effect. |
| T-03-213 | Tampering | corrupting the consent file | medium | mitigate | Validated whole, atomic write, mode 0600, size cap, never overwriting an invalid file. |
| T-03-214 | Repudiation | collecting a type the user did not approve | high | mitigate | `renderReport` includes approved types only; versioned field lists revert changed types; tests for both. |
| T-03-215 | Information Disclosure | any network traffic | high | mitigate | Nothing in this plan calls the network; a test stubs fetch and http request functions to throw and runs every sub-command. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package. |
