## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent to permission store | An agent must have no route to write or widen permissions. |
| repository text to the terminal prompt | Manifest text is shown to the human and must not travel anywhere an agent reads. |
| terminal to user-level config | The one place a permission is created. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-03-151 | Elevation of Privilege | an agent causing an `allow` write through MCP | critical | mitigate | No MCP tool for it; Host refuses `allow` with MCP origin (`allow_forbidden`); a non-terminal CLI run is refused; tests for each. |
| T-03-152 | Tampering | a preview that differs from what is written | high | mitigate | The write step recomputes the hash from its own arguments and requires it to equal the previewed hash (`confirm`). |
| T-03-153 | Tampering | clobbering or corrupting the user's config | high | mitigate | Validate before write, refuse to overwrite an invalid file, temp file plus rename, 0600, size cap, preserve other keys; failure tests. |
| T-03-154 | Information Disclosure / injection | manifest argv text reaching an envelope or agent-visible message | high | mitigate | Fixed-text diagnostics and reasons; the argv appears only on stderr at the prompt; a secret-marker test. |
| T-03-155 | Elevation of Privilege | MCP-origin commands running because the config allows them | high | mitigate | The MCP-origin runner is built without the user permission list unless `--allow-build`; origin matrix test. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package. |
