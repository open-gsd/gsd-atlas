## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tenant and recorder data to a bundle file | Identifiers, paths and arguments from the user's repository become text in a file the user may share. |
| user text to the bundle | Free text may carry paths and secrets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-321 | Information Disclosure | names, paths or secrets in a shared bundle | high | mitigate | Typed leaves through one sanitiser; hashed by default with an unstored per-bundle HMAC key; privacy-fixture test with five markers across all three modes; user text scrubbed; source text and `untrusted_text` never collected. |
| T-03-322 | Information Disclosure | dictionary recovery of hashed names | medium | mitigate | HMAC with a random key that never leaves memory, so a symbol-name dictionary cannot be hashed to match; tokens are unlinkable across bundles. |
| T-03-323 | Repudiation | a preview that differs from the file | medium | mitigate | Preview and file are generated from one sanitised tree; a test compares the bytes; the write is bound to the digest. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package. |
