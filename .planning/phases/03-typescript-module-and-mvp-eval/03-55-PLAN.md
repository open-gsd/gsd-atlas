| Boundary | Description |
|----------|-------------|
| module manifest to a process start | A manifest proposes a command; only user-level config can make the runner start it. |
| command output to the answer stream | Output of a third-party command is untrusted and must not enter envelopes, metrics or logs. |
| eager pass to resources | A large repository makes the eager pass long. |
