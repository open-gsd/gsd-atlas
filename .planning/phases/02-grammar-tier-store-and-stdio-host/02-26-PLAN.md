## Artifacts this phase produces (plan 02-26)

- `scripts/corpus-gates.ts`: `runCorpusGates(options)` with options {corpus: 'gsd-core', keep?: boolean, buildCommand?: injected}; checks: indexed paths subset of the checkout's `git ls-files`, accounting identity (indexed plus skipped plus unclaimed equals snapshot size), parse-error file ratio per module at most 0.005 (read from the store's files table through the SQLite kit, read-only), database size at most the approved gate.storeMaxBytes, second build parses zero files, elapsed times printed; the command line fetches the corpus with `fetchCorpus` and removes it afterwards.
- `scripts/freshness-gate.ts`: `percentile(sorted, p)` (nearest-rank), `runFreshnessGate({ saves, maxMs, files })`; generates a synthetic TypeScript repository of the given file count, starts a Host with the real watcher, performs the saves, prints p50, p95 and p99 in milliseconds and exits 1 when p99 exceeds `maxMs`.
- `package.json` scripts: `gates:corpus` = `node scripts/corpus-gates.ts`, `gates:freshness` = `node scripts/freshness-gate.ts`, `size-gate` = `node scripts/size-gate.ts`.

- `modules/*/grammar.lock`: `wasm.platforms["win32-x64"]` (and any other platform CI proves) from evidence.
- README: Phase 2 quickstart section.
