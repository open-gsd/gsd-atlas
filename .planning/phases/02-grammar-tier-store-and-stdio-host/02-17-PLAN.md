<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository `.git` file to the watcher | A linked worktree's `.git` file names a directory; a hostile repo could name anything. |
| native watcher events to the Indexer | Events come from the OS and may be flooded, lost or reordered. |
| npm registry to the dependency tree | A native-addon package is added. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-02-56 | Information Disclosure | watching a directory a repo file merely names | high | mitigate | Only the roots reported by `git worktree list` and the common git directory from SourceTree.identity() are watched; the gitdir named by a `.git` file must resolve (realpath) inside the common git directory or it is ignored; test with an escaping `.git` file. |
| T-02-57 | Denial of Service | event floods and lost events | medium | mitigate | Coalescing queue with maximum wait, ignore globs for node_modules and .git, Reconcile on overflow and error and on a timer, bounded Governor queues. |
| T-02-58 | Tampering | @parcel/watcher supply chain (native addon with an install script) | medium | mitigate | Audit verdict OK (years old, 41M weekly downloads); pinned exact version; installed with scripts disabled (prebuilt optional package used, verified on darwin-arm64; CI proves the other OSes); the lockfile diff is reviewed in the acceptance criteria. |
| T-02-59 | Denial of Service | native watcher unavailable on a platform | low | mitigate | reconcile-only mode keeps answers correct through the timer and ensureFresh. |
| T-02-SC | Tampering | npm/pip/cargo installs | medium | mitigate | Package-legitimacy gate: RESEARCH.md audit table exists and marks @parcel/watcher OK (no [ASSUMED], [SUS] or [SLOP] entries for this install), so no checkpoint precedes it; exact pin; scripts disabled. |
