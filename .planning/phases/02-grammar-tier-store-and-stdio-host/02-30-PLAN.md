## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process to process (SQLite WAL) | A follower in another process holds read snapshots of the file the leader compacts. |
| leader's event loop to requests | Compaction runs synchronously on the loop that answers requests. |
| facts to the names table | Names come from extractors that read repository text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-104 | Denial of Service | full VACUUM in the idle loop | medium | mitigate | VACUUM runs only after a completed collect and only past the two recorded thresholds; the hysteresis (a vacuumed file is about 26 percent empty against a one-third trigger) stops it repeating; the pause is a documented exception (02-CONSTANTS.md addendum, ADR amendment in plan 02-42) and the size gate prints its measured length (plan 02-37). The yield check in the Tenant's round happens before every slice, and a VACUUM that has started cannot be cut short. |
