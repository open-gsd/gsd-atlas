<objective>
Close the data-integrity half of WR-05 (fact validation never checks names) and remove the dead `collected` file state (IN-02). Both live at the boundary where extractor output becomes store rows.

Phase goal (ROADMAP.md, quoted verbatim): "A developer can build a local fact index of gsd-core on macOS, Linux or Windows and ask cited, fresh, worktree-correct questions (find, refs, context, impact) through the CLI or a stateless stdio MCP server."

Purpose: every fact carries valid provenance (LNG-04) and the file lifecycle that the size gate depends on (STO-05, D-16) is described by code that can actually run.
Output: stricter validation with tests, and a simpler writer with a test that states what really happens.
</objective>
