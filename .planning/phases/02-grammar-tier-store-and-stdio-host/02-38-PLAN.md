<objective>
Bound every git call the Source Tree makes (WR-07), stop it from buffering blobs it is about to discard (WR-08), and make the store identity independent of root-commit print order (WR-06).

Phase goal (ROADMAP.md, quoted verbatim): "A developer can build a local fact index of gsd-core on macOS, Linux or Windows and ask cited, fresh, worktree-correct questions (find, refs, context, impact) through the CLI or a stateless stdio MCP server."

Purpose: one hung or hostile repository must not wedge the Host (HST-03), a `history` request must not allocate hundreds of megabytes (STO-09), and a store must keep its identity across the ordinary operations of a repository with several roots (STO-07).
Output: a hardened Source Tree with structural tests; the contract suite covers the new cap on the fake and the real implementation.
</objective>
