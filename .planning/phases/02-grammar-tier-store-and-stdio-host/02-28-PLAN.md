## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| answers to the metrics database | Everything recorded crosses from request handling into persistent storage on disk. |
| process to process (lease) | Two processes can run against one repository and only one may write. |
| quiet time to request time | Background work competes with interactive requests for CPU and the writer slot. |
