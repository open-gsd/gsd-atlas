## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `fresh` paths from agents to the file system | Agent-supplied path strings are turned into reads and hashes. |
| repository bytes to the parser | Arbitrary source enters the engine. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-48 | Information Disclosure | ensureFresh path traversal and symlink escape | high | mitigate | Absolute, dot-dot and NUL paths rejected into `invalid`; realpath containment check against the worktree; the test asserts rejected paths are never read or hashed. |
| T-02-49 | Denial of Service | event floods (build output, node_modules churn) | medium | mitigate | Per-(worktree, path) coalescing with a maximum wait bounds job count per path; the indexing-class queue is bounded by the Governor and answers busy; sourceSet drops unclaimed extensions before any parsing. |
