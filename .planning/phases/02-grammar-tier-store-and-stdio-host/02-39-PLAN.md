<objective>
Give the parser pool's grammar loads a deadline (WR-09) and stop the pool from killing a worker at the same instant the engine would cancel the parse itself (IN-06).

Phase goal (ROADMAP.md, quoted verbatim): "A developer can build a local fact index of gsd-core on macOS, Linux or Windows and ask cited, fresh, worktree-correct questions (find, refs, context, impact) through the CLI or a stateless stdio MCP server."

Purpose: LNG-07 (workers stay healthy and memory does not grow unbounded) must hold against modules that come from the repository being indexed.
Output: a pool with bounded loads and a parse cut-off that lets workers survive slow parses.
</objective>
