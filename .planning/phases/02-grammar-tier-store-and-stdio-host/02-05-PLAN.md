## Trust Boundaries

| Boundary | Description |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-11 | Information Disclosure | readText path traversal and symlink escape | high | mitigate | Reject empty, NUL, absolute and `..` paths; lstat refuses a final-component link; realpath containment check against the canonical worktree path; contract and real-only cases cover `..`, absolute, NUL and a symlinked directory. |
| T-02-12 | Elevation of Privilege | repo-configured filter drivers during hash-object and check-attr | high | mitigate | Every spec is built by gitSpec with the pinned -c overrides and environment and the neutralised filter names; hashPaths enumerates filters on every call (no caching) so a newly added driver is never missed. |
| T-02-13 | Denial of Service | huge, binary or pathological files and huge path lists | medium | mitigate | 8 KB peek only, byte cap, batches of 64, output caps on git specs, approved git timeouts. |
| T-02-14 | Information Disclosure | indexing ignored secret files | medium | mitigate | The source set can only be built from snapshot or hashPaths output, which come from ls-files with exclude-standard; the contract world includes an ignored secret that must never appear. |
