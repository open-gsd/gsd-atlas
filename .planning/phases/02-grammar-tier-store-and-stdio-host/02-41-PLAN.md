<objective>
Make the read-only tools read-only (WR-01), finish the `not_indexed` flow so the command it names works (WR-02), stop the Host from keeping every tenant for the life of the process (WR-10), and replace the Host's two broken containment tests (IN-03).

Phase goal (ROADMAP.md, quoted verbatim): "A developer can build a local fact index of gsd-core on macOS, Linux or Windows and ask cited, fresh, worktree-correct questions (find, refs, context, impact) through the CLI or a stateless stdio MCP server."

Purpose: QRY-06 says the default tools are read-only; D-11 says an unindexed repository answers `not_indexed` naming the command and nothing auto-builds; D-01 says the first opener leads. Today one question about any repository an agent names creates state in its `.git` directory and takes its writer lease, so the advertised `gsd-atlas build` fails with exit 3.
Output: a Host that opens a store only when it holds an index or when asked to build, evicts idle tenants, and answers consistently through the CLI and MCP.
</objective>
