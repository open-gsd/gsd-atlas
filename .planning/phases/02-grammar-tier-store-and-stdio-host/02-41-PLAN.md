## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent-supplied `repo` / `cwd` to the file system | These strings name any directory the user can read; they are controlled by a possibly prompt-injected agent. |
| Host to repository storage | Opening a store creates files in `.git` and takes the repository's writer lease. |
| agent session lifetime to resource lifetime | A long-lived server accumulates whatever the agent touches. |
