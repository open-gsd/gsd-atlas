## Artifacts this phase produces (plan 02-16)

- `src/query/types.ts`: `Query` {ask(request: Request): Promise<Envelope>}; `QueryDeps`; `QueryConfig` (budget, ceiling, line width, limits, cursor size; defaults from the approved constants in `defaults.ts`).
- `src/query/tools.ts`: `TOOL_NAMES`; `TOOLS`: array of {name, title, description, inputSchema (zod object), readOnlyHint: true}. Common optional arguments on every code tool: `repo` (path), `cwd` (path hint), `budget_tokens`, `more` (cursor), `fresh` (array of repo-relative paths). `code_find`: `name` (required, non-empty after trim), `kind` (symbol kind filter), `mode` (`exact` | `prefix` | `fuzzy` | `auto`, default `auto`), `limit`. `code_refs`, `code_context`, `code_impact`: `name` required, `path` optional (disambiguates the defining file), `limit`; `code_impact` also `depth`. `atlas_status` and `lang_list`: `repo` only. `buildRequest(tool, input)` returns the Request {protocol, kind: tool, args, budget_tokens, fresh, worktree?}.
- Envelope schema ids: `gsd-atlas.code-find/1`, `gsd-atlas.code-refs/1`, `gsd-atlas.code-context/1`, `gsd-atlas.code-impact/1`, `gsd-atlas.atlas-status/1`, `gsd-atlas.error/1` for query-level errors.
- Query diagnostics: `invalid_args` (error), `not_indexed` (error, message names `gsd-atlas build`), `bad_cursor` (error), `output_too_large` (error), `invalid_fresh_path` (warning).
- Fence format: each untrusted entry text is `BEGIN-UNTRUSTED-{nonce}`, a newline, the normalized line, a newline, `END-UNTRUSTED-{nonce}`; omission marker text is `[line omitted]` inside the same fence.
- Sort key tuple: [tier, kindRank (definition 0, reference 1), confidenceRank (EXTRACTED 0, INFERRED 1), exportedRank (exported 0, local 1), dirDistance, path, line, col, handle].
- `src/query/harness.test.ts`: test helper `createHarness()` building a temp git repository with source files, a real fact store populated through the Writer from hand-made FileFacts, and a real SourceTree; no test inside it.
