<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| import specifiers (attacker-chosen strings) to path resolution | Specifiers are resolved against overlay paths only; they never touch the file system. |
| the injected Resolver to the store | A resolver (a precise adapter in Phase 3) returns edges that are cached. |
| query text to FTS5 | The fuzzy query is parsed by the FTS5 query syntax. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-02-32 | Tampering | FTS5 query syntax injection through the fuzzy name | medium | mitigate | The query is always wrapped as one quoted phrase with embedded quotes doubled and bound as a parameter, so operators (AND, NEAR, column filters) cannot be injected; a test with such strings. |
| T-02-33 | Information Disclosure | specifier resolution reading outside the repo | low | mitigate | resolveSpecifier is a pure function over the overlay path set and never touches the file system; `..` segments that escape the root resolve to no candidate. |
| T-02-34 | Denial of Service | pathological import graphs or cyclic calls | medium | mitigate | Visited sets, a depth clamp of 5 and a result limit bound every walk. |
| T-02-35 | Tampering | resolver returning edges for sites or targets not in the overlay | medium | mitigate | Cached and returned edges are filtered to sites present in the overlay and targets that exist in it; others are dropped. |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed by this plan. |
</threat_model>
