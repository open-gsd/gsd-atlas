<objective>
Make the CommandRunner's git gate stand on its own, as its header promises, by replacing the exact-token denylist with a per-subcommand allowlist (WR-11), and tighten the inherited-environment denylist with the variables the review named (IN-05, partial).

Phase goal (ROADMAP.md, quoted verbatim): "A developer can build a local fact index of gsd-core on macOS, Linux or Windows and ask cited, fresh, worktree-correct questions (find, refs, context, impact) through the CLI or a stateless stdio MCP server."

Purpose: the gate is the last line of defence against a spec that writes to a repository (STO-09) or runs repository-controlled code (LNG-05); today `git hash-object -wt blob` passes because `-w` is only denied as a whole token.
Output: a stricter `decide.ts`, a matrix of accepted and denied specs, a real-repository run proving a denied write never happens.
</objective>
