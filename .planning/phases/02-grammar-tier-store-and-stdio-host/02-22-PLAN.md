## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-02-76 | Tampering | argument injection through repo-derived names passed by scripts | medium | mitigate | parseArgs is strict, values are validated by the shared zod schemas, no shell is involved anywhere, and the Host re-validates everything. |
| T-02-77 | Information Disclosure | stderr or stdout carrying repo text outside the fenced field | medium | mitigate | stdout is the Host's envelope unchanged (repo text only inside untrusted_text); stderr lines are built from diagnostic codes and fixed messages, with repo-derived subjects normalized by the Query layer. |
| T-02-78 | Denial of Service | a CLI process left running by pending timers | low | mitigate | The bin disposes the Host in `finally`, which cancels all timers and watchers; the end-to-end tests exit without a forced kill. |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed by this plan. |
