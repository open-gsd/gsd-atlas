Output: `src/grammar-engine/pool/*`, an index export, tests including a memory plateau run.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo source text to a worker thread | Hostile source is parsed inside a worker, isolating parser crashes from the Host. |
| main thread to worker messages | Plain data crosses; grammar bytes are hash-checked inside the engine each worker runs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-02-44 | Denial of Service | a pathological file hanging a parse | high | mitigate | Per-run deadline terminates the worker and respawns; the run rejects with parse_timeout (prohibition above); tested with a spinning worker. |
| T-02-45 | Denial of Service | WASM memory growth over thousands of files | high | mitigate | Deterministic deletes in with-tree.ts, recycling after the approved number of runs, and the relative RSS plateau test on all three OSes. |
| T-02-46 | Tampering | a tampered grammar WASM sent to a worker | medium | mitigate | The engine inside every worker checks the sha256 before instantiation exactly as in-process (contract case for hash mismatch). |
| T-02-47 | Denial of Service | unbounded queue of runs | low | accept | The Indexer bounds its own submissions through the Governor (indexing class queue bound); the pool queue is FIFO and drains. |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed by this plan (worker_threads is built in). |
</threat_model>
