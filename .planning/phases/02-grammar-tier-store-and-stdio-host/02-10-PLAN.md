## Artifacts this phase produces (plan 02-10)

- Closed vocabularies in `src/metrics/types.ts`: `TOOL_NAMES` = code_find, code_refs, code_context, code_impact, atlas_status, lang_list; degraded values are `DEGRADED_CODES` from src/facts; `LATENCY_BUCKETS_MS` = 1, 2, 5, 10, 20, 50, 100, 200, 500, 1000, 2000, 5000 plus an overflow bucket; `LAG_BUCKETS_MS` = 10, 50, 100, 250, 500, 1000, 2000, 5000 plus overflow.
- `MetricsEvent` union: `answer` {tool, ok, latencyMs, results, estimatedTokens, truncated, degraded: readonly DegradedCode[]}; `freshness` {lagMs}; `index_health` {files, errorFiles, staleFiles, sizeBytes}. Each event may carry `at` (ms) set by the recorder from the injected Clock, never by callers.
- `Metrics` {record(event): void, flush(): Promise<void>, report(range): Promise<MetricsReport>, reset(): Promise<void>, rollup(): Promise<void>, status(): MetricsStatus, close(): Promise<void>}; `MetricsStatus` {recording: boolean, reason?: string, queued, dropped, rejected, writeFailures}.
- `MetricsReport`: {range, answers: {total, ok, byTool, truncated}, degraded: {code: count}, freshness: {count, p50UpperBoundMs, p95UpperBoundMs}, indexHealth: {files, errorFiles, staleFiles, sizeBytes, at} or null, tokens: {estimatedTotal, byTool, label: 'estimate'}}.
- `openMetrics(path, deps, options?)` with deps {clock} and options {driver?, busyTimeoutMs?, queueMax?, flushIntervalMs?, retentionDays?, rollupAfterDays?, migrations?}; defaults are the approved constants; it never throws: on failure it returns a disabled instance whose status.reason names the cause.
- Tables (migration 1): `counters(grain, bucket, metric, dim, value)` primary key (grain, bucket, metric, dim) with grain `hour` or `day`; `gauges(metric, value, at)`; `meta(key, value)`.
