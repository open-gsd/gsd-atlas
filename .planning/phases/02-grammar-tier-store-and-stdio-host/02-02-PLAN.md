## Artifacts this phase produces (plan 02-02)

- `src/facts/file-facts.ts`: `REF_KINDS` = call, new, read, type, heritage, member and type `RefKind`; `IMPORT_STYLES` = es, cjs, side-effect, reexport and type `ImportStyle`; `ImportBinding` {imported, local} (`imported` is the exported name, `default` for a default import, `*` for a namespace import); `ExportSite` {name, local?, span, from?}; optional `LocalSymbol.exported`, `RefSite.kind`, `RefSite.enclosing` (index into `symbols`, absent for a top-level site), `ImportSite.style`, `ImportSite.bindings`, `FileFacts.exports`.
- `src/facts/degraded.ts`: `DEGRADED_CODES` with `reconciling`, `rebuilding`, `watermark_moved` appended.
- `src/facts/request.ts`: `Citation` {id, path, line, col, endLine, endCol, confidence, debug, text_ref?} (line and col are 1-based for display, span fields stay 0-based elsewhere); `UntrustedEntry` {ref, text}; `UntrustedText` {nonce, entries}; `EnvelopeExtras` {citations?, watermark?, untrusted_text?, truncated?, more?, hints?, retry_after?}; `Envelope` extended with those optional fields (`retry_after` is a number of milliseconds, present only on a busy error); `okEnvelope(schema, data, diagnostics?, extras?)` and `failEnvelope(schema, diagnostics, extras?)`.
- `src/facts/index.ts` re-exports all of the above.
- `src/facts/clock.ts`: `Clock.after(ms: number, fn: () => void): () => void` (required; returns a cancel function that is idempotent and a no-op after the callback ran); `systemClock.after`. `src/test-kit/fake-clock.ts`: `FakeClock.after`, fired by `advance` in due-time order together with sleepers (ties in call order).
