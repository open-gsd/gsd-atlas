## Artifacts this phase produces (plan 02-06)

- `src/fact-store/schema.ts`: `SCHEMA_VERSION` = 1 and `createSchema(db)` creating tables `meta`, `names`, `files` (state live, retired or collected; stale flag; first_seen, last_seen), `symbols`, `refs`, `imports`, `import_bindings`, `exports`, `overlays` (worktree, ref, seq) and `overlay_files` (worktree, path, hash, file_id which is null while facts are pending); every fact table is keyed by `file_id` and is WITHOUT ROWID where its key is composite. Plans 02-11 adds `resolution_contexts`, `resolved_edges` and `names_fts` to the same unreleased version 1.
- `src/fact-store/open.ts`: `openFactStore(dir, deps, options?)` with `StoreOptions` {repo?: string, driver?: DriverName, busyTimeoutMs?: number, version?: string}; assignable to `OpenStore`. It creates the directory, sets auto_vacuum INCREMENTAL before the first table, opens the writer connection and a read-only connection, creates the schema, writes `meta.schema_version` and `meta.created_by`, and refuses a newer store with `SchemaTooNew`.
- `src/fact-store/store.ts`: `createStore(parts)` assembling `FactStore` (at, writer, reconcile, collect, compact, check, maintain, status, close); in this plan `reconcile` and `status` are real, and `collect`, `compact`, `check`, `maintain` return `{complete: true, spentMs: 0, processed: 0}` or `{ok: true, problems: []}` until plan 02-18 replaces them (documented in JSDoc as unimplemented-by-design here; the contract does not assert on them).
- `src/fact-store/writer.ts`: `createWriter(parts)` with `commitFile`, `link`, `setOverlay`, `dropOverlay`, `markStale`, `release`.
- `src/fact-store/reader.ts`: `createReader(parts, worktree)` with `find` (exact, prefix, fuzzy as a bounded LIKE scan), `symbol`, `fileFacts`, `refs`, `callers` (one hop) and `importers` (direct, exact path match).
- Types in `src/fact-store/types.ts`: `StoreOptions` {repo?: string, driver?: DriverName, busyTimeoutMs?: number, version?: string, canCache?: () => boolean (whether this process may write derived caches; plan 02-12 wires it to the writer lease, default always true), resolutionContext?: () => ResolutionContext (plan 02-11 reads it; default id grammar with no config hashes)}; `Writer.link(worktree, path, hash): Promise<CommitResult>`; `SymbolRecord.exported?: boolean`; `RefRecord.kind?: RefKind` and `RefRecord.enclosing?: SymbolIdentity | null`; `ImporterRecord` extends Provenance {importer: string, specifier: string, style?: ImportStyle, hops: number}; `ImportersOptions` {depth?: number, limit?: number}; `Reader.importers(path, options?)` returning `Answer<readonly ImporterRecord[]>`.
- Contract: `defineFactStoreContract(label, driver)` in `src/fact-store/contract.ts` (test code, not exported from index.ts); `src/fact-store/store.test.ts` calls it for `node:sqlite` and `better-sqlite3`.
- Debug handle format (opaque to callers): `sym/` + percent-encoded path + `/` + content hash + `/` + definition order.
- Symbol identity: `repo` from `StoreOptions.repo` (default the store directory's base name), `path` the overlay path, `qualifiedName` the symbol's qualifiedName or its name, `kind`, and `discriminator` the zero-based index among symbols in the same file sharing qualifiedName and kind when more than one share them.
