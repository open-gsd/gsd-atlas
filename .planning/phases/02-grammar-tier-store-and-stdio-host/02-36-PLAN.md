<objective>
Make both bins shut down cleanly on SIGTERM and SIGINT (IN-07) and make the CLI compose the Host lazily and inside its try block (IN-09).

Phase goal (ROADMAP.md, quoted verbatim): "A developer can build a local fact index of gsd-core on macOS, Linux or Windows and ask cited, fresh, worktree-correct questions (find, refs, context, impact) through the CLI or a stateless stdio MCP server."

Purpose: HST-01 (a stdio server that comes and goes between tool calls) and STO-06 (a store that survives abuse) both want an orderly exit when an MCP client signals instead of closing stdin; QRY-04 wants the CLI's failure modes to stay on its one error line.
Output: a shutdown helper with tests, two small bin edits, and a real-process test.
</objective>
