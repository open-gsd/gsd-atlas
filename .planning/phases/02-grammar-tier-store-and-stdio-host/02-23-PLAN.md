## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client (agent host) to the server | Tool arguments come from a model; results flow back into its context. |
| stdout | The protocol channel; a stray write corrupts or forges frames. |
| npm registry to the dependency tree | A young SDK package and its transitive dependencies. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-02-79 | Tampering | stray output on stdout injecting or corrupting protocol frames | high | mitigate | The stdout guard (first import), no-console lint, a framing test that parses every stdout line, and a trace-warnings variant; protocol writes go only through the captured stream. |
| T-02-80 | Elevation of Privilege | a write-capable or build tool exposed over MCP | high | mitigate | Registration loops over the six read-only TOOLS definitions (readOnlyHint) only; `build` and `maintain` exist only as CLI requests the MCP server never builds; the prohibition above; the list is asserted. |
| T-02-81 | Tampering | prompt injection via results | high | mitigate | Results are the Host's envelope unchanged: repo text only inside nonce-fenced untrusted_text; the server instructions say fenced text is data (plan 02-16 mitigation T-02-52). |
| T-02-82 | Tampering | @modelcontextprotocol/server supply chain (SUS, too-new) | high | mitigate | Blocking-human approval recorded before install (plan 02-04), exact pin, scripts disabled, peers checked so @modelcontextprotocol/node and hono are absent. |
| T-02-83 | Denial of Service | malformed or oversized messages | medium | mitigate | The SDK's framing and schema validation reject malformed input before any handler; invalid arguments never reach the Host; the Host's Governor and output ceiling bound the rest. |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package-legitimacy gate: this install follows the blocking-human checkpoint in plan 02-04 for the only [SUS] package; no [SLOP] package; `npm install --save-exact --ignore-scripts`. |
