## Artifacts this phase produces (plan 02-07)

- `Capture` gains `match: number` (zero-based index of the query match within its query kind, in the order `Query.matches` returns them); captures of one match share it.
- `createGrammarEngine(options?)` gains `GrammarEngineOptions` {matchLimit?: number, parseTimeoutMs?: number}; `GrammarRunError` codes gain `parse_timeout` and `match_limit_exceeded` (added to `GrammarRunErrorCode`).
- `GRAMMAR_LIMITS.captureTextChars` = 256.
- `src/grammar-engine/extract.ts`: `extractFileFacts(input: ExtractInput): ExtractResult` where `ExtractInput` = {path, contentHash, module, grammarVersion, run: GrammarRunResult} and `ExtractResult` = {facts: FileFacts, diagnostics: Diagnostic[]}; diagnostics have codes `match_missing_name` and `match_missing_path` (info, one per skipped match, aggregated count in the message) and are never fatal.
- The capture-name vocabulary (documented in the extract.ts header; module authors write queries to it):
  - tags query: `definition.<kind>` on the whole definition node, `name` on its identifier, optional `export` on the exporting statement. The kind string after `definition.` becomes `LocalSymbol.kind`.
  - imports query (imports and exports, because the manifest has exactly three query files): the statement node captured as `import.es`, `import.cjs`, `import.side-effect` or `import.reexport` (the suffix is `ImportSite.style`), `import.path` on the path string, and per-binding captures `import.default` (local name), `import.namespace` (local name), `import.named` (imported name) with `import.local` for the local alias when different; one match per binding is allowed, matches that share a statement span merge into one ImportSite. Exports: the statement or assignment captured as `export`, `export.name`, optional `export.local` and `export.from` (the re-export source string).
  - refs query: `reference.call`, `reference.new`, `reference.read`, `reference.type`, `reference.heritage` or `reference.member` on the identifier node.
- Toy module: `queries/imports.scm` captures the whole `use_stmt` as `import.es`; the four goldens are regenerated.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo source text to the parser | Arbitrary, possibly hostile source (huge, deeply nested, pathological) is parsed and queried. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|

| T-02-20 | Tampering | a hostile module emitting captures that make the extractor produce inconsistent FileFacts | medium | mitigate | The extractor builds parents and enclosing indexes itself from spans (never from capture data), skips malformed matches with a counted diagnostic, and every output is validated by validateFileFacts in tests; the writer re-validates before storing (plan 02-06). |
| T-02-21 | Information Disclosure | capture text carrying large source fragments over a worker boundary | low | mitigate | Text over 256 UTF-16 code units is dropped. |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed by this plan. |
