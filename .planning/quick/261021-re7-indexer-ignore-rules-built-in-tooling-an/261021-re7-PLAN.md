<objective>
Index only code: stop indexing tooling and build cruft (node_modules at any depth, build outputs, caches, minified bundles) even when the repository has no .gitignore for them, and let a repository shrink its own index further with a git-syntax `.atlasignore`. Everything is decided by git's own matcher; the exclusions apply on every path the indexer uses; the counts are reported without a single path name.

Purpose: stale or vendored files crowd out real answers and cost indexing time. The task text asks for measured, not guessed, scope for tracked files, a trust story that keeps a repo-supplied file non-privileged, and test-first delivery.

Output: a committed measurement record, one defaults constant with tests, vetted `.atlasignore` support in the real and fake Source Tree, the minimal git allowlist extension, Indexer/follower/Tenant/status wiring, two dated ADR amendments and two user-documentation pages.
</objective>

Facts verified while planning (git 2.54.0 on macOS, scratch repos; Task 1 re-verifies and commits them):
- `--exclude <pattern>` (separate token), `--ignored` and `--cached` long forms work. `--exclude` patterns prune untracked directories at any depth; `--cached --ignored --exclude P` lists the tracked paths P matches (the only way to drop tracked paths) and does not walk the work tree.
- Command-line excludes beat per-directory files: a `!node_modules/` line in a per-directory file did not re-include the default, for untracked and for tracked paths.
- CRITICAL: `--exclude-standard` and `--exclude-per-directory=<file>` replace each other (the later one on the command line wins), so one run cannot apply both `.gitignore` and `.atlasignore`. Hence design DD-2 below (two listings intersected).
- A symlinked `.atlasignore` is not followed by git (a warning on stderr, exit 0, rules not applied); git does not reject invalid UTF-8, so the malformed-input check is ours.
- Baselines at planning time (HEAD bafbdd5): `git status --porcelain` is empty for the registered evaluation paths; a default literal such as the parcel-cache directory appears in no non-test file under src/; docs/ev[a]l/angular-pilot-plan.md does not exist yet (another agent drafts it).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository files to Source Tree | a cloned repository supplies `.atlasignore`, `.gitignore`, file names and sizes: all untrusted |
| Source Tree to git argv | only constants may cross; repository and watcher text never becomes an argument |
| Source Tree to diagnostics, status and build envelope | counts and fixed text only; no path or repository text |
| agent request to ensureFresh | agent-named paths are untrusted and must get the same ignore verdict as watcher paths |
